I have been working on a community package for Umbraco Bellissima called ContentLock, which lets users lock content nodes and see who else is logged in to the backoffice. Some of this work uses SignalR to push realtime updates to the backoffice UI.

Registering the options

Bind the section with AddOptions<ContentLockOptions>() in a composer, then read it through IOptionsMonitor.

  • Create an interface for the SignalR hub and its methods
  • Create the hub from that interface
  • Register the route in the UmbracoPipelineFilter
builder.Services
   .AddOptions<ContentLockOptions>()
   .Bind(builder.Config.GetSection(ContentLockOptions.ConfigName));

Hope this has inspired you to play around with SignalR and Bellissima.
