The "What makes it good" section of a case study: three to six numbered points, each a short heading and two sentences.

Markup: `<ol class="hmd-features">` of `<li><h3>…</h3><p>…</p></li>`; the large numbers come from a CSS counter.

- The consumer provides points that are concrete and checkable ("Locks update live for every editor through SignalR"), not adjectives ("Fast", "Modern").
- Lead with the point that matters most to someone hiring: the problem it solves for editors or developers. Put technical choices second.
- Three to six items. Use an ordered list only because the numbers are visible; the order should still read well.
- Also usable for "How I work" on the hire pages.
