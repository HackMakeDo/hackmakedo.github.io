ContentLock

ContentLock is a free, open source Umbraco package that stops editors overwriting each other's work, by letting them lock a content node while they work on it.

What makes it good

  1. No more overwritten work

    Editors lock a content node while they work on it, so two people cannot save over each other.

  2. Live for everyone

    Lock changes and online users are pushed to every backoffice through a SignalR hub.

  3. Switch features without a deploy

    Options are read through IOptionsMonitor, so turning a feature off in settings updates connected backoffices.

  4. Talk to each other

    Quick audio calls between connected backoffice users.
